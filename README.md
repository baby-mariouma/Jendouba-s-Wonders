Projet Module 
1. Réaliser un site web en utilisant les technologies suivantes : HTML5, CSS3 et JavaScript. 
Le thème du site est proposé par vous-même. Le site web doit contenir au moins les 
pages web suivantes : 
▪ Une page index.html qui introduit le contenu du site.  
▪ Des pages qui décrivent les éléments du thème choisi. Ils doivent contenir :  
✓ Des listes 
✓ Des images  
✓ Des tableaux  
✓ Des images cliquables et réactives  
✓ Une vidéo et un audio 
✓ Des liens internes et externes 
✓ Les éléments de structuration des sections (header, footer, …) 
✓ Un formulaire 
▪ Une seule feuille style.css pour la mise en forme du site et d’autres styles internes.  
2. Ajouter des scripts JavaScript en utilisant : 
✓ Les fenêtres de dialogues suivantes : prompt, alert et confirm 
✓ Des fonctions, des structures conditionnelles et des structures itératives 
✓ La manipulation des objets du document (DOM): récupération, édition et ajout 
des éléments. 
✓ Quelques événements : onMouseOver, onClick,…
